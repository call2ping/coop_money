# 💰 เปรียบเทียบดอกเบี้ย เงินฝาก / เงินกู้

เว็บแอปไฟล์เดียว (HTML/CSS/JS ล้วน ไม่มี dependency) สำหรับเปรียบเทียบดอกเบี้ย 2 อัตราในระยะเวลาที่ต้องการ
คิดดอกเบี้ย **รายวัน ฐาน 365 วัน** ตามวิธีที่สหกรณ์ออมทรัพย์ใช้จริง

## วิธีคิดดอกเบี้ย

ดอกเบี้ยงวดหนึ่ง = `ยอดคงเหลือ × อัตราต่อปี × จำนวนวันจริงในงวด ÷ 365`

จำนวนวันนับจาก **วันที่เริ่ม** ที่กรอก ตามปฏิทินจริง (เดือน 28/29/30/31 วันไม่เท่ากัน, ปีอธิกสุรทินมี 366 วันแต่ยังหารด้วย 365)

## ฟีเจอร์

- **โหมดเงินฝาก** — เทียบ 2 อัตรา เลือกได้ว่าดอกเบี้ยที่ตั้งจ่าย **ทบเข้าบัญชี** หรือ **รับออกไป** และตั้งจ่ายถี่แค่ไหน (รายเดือน / ไตรมาส / 6 เดือน / ปี) · เงินฝากเพิ่มรายเดือนเริ่มเดินดอกวันถัดจากวันฝาก
- **โหมดเงินกู้** — เลือกอัตราและรูปแบบการชำระของแต่ละฝั่งได้อิสระ
  - **สหกรณ์** — ส่งเงินต้นเท่ากันทุกงวด + ดอกเบี้ยรายวันจากยอดคงเหลือ (ค่างวดลดลงเรื่อย ๆ)
  - **ธนาคาร** — ลดต้นลดดอก แต่เกลี่ยให้ผ่อนเท่ากันทุกงวด
  - **Flat** — ดอกเบี้ยคิดจากเงินต้นเต็มจำนวนตลอดสัญญา
  - แสดง **EIR (อัตราดอกเบี้ยที่แท้จริงต่อปี)** ของทุกฝั่ง คำนวณจากกระแสค่างวดจริงด้วย IRR ทบต้นรายวัน
- กราฟเส้น + ตารางรายปี + สรุปส่วนต่างดอกเบี้ย
- คำนวณสดทันทีที่กรอกค่า

## ข้อจำกัดของโมเดล

- วันครบงวดใช้วันครบรอบเดือนจากวันที่เริ่ม ไม่ใช่วันตัดยอดตายตัวของแต่ละสหกรณ์ (เช่น สิ้นเดือน หรือ 31 มี.ค./30 ก.ย.)
- ไม่รวมค่าธรรมเนียม เงินปันผล เงินเฉลี่ยคืน หรือเงินค้ำประกัน
- ดอกเบี้ยเงินฝากในสหกรณ์ได้รับยกเว้นภาษีเงินได้บุคคลธรรมดา จึงไม่หัก 15% เหมือนเงินฝากธนาคาร
